# Intent: Workspace Core

## ビジネス目的

複数リポジトリを横断して開発するエンジニアが日常的に行っている「リポジトリごとのブランチ切り替え・エディタの開き直し」という煩雑なコンテキストスイッチを排除する。

**「1つの開発タスク（Feature）＝ 1つの統合されたWorkspace」** という開発体験を提供し、Gitの `bare repository` + `worktree` を裏側に隠蔽することで、ゼロ・コンテキストスイッチかつディスク管理不要な並列開発環境を実現する。

## ステークホルダー

- **Primary**: マイクロサービス構成など複数リポジトリを日常的に扱うエンジニア（フルスタック、バックエンド、インフラ）
- **Secondary**: チームリーダー（複数タスクの並行管理）、プロジェクトマネージャー（開発環境の標準化）

## 期待される成果

- Workspace作成からVS Code起動までを数秒以内で完了できる
- 複数タスク（Feature開発・Hotfix等）を同時並行で、互いに干渉なく進められる
- リポジトリごとに異なるブランチを組み合わせた非対称構成を直感的に構築できる
- `~/.squad` 配下にデータを隔離し、ユーザーの作業ディレクトリを汚染しない
- 不要なWorkspaceをワンクリックで完全消去（Worktree実体 + 設定ファイル）できる

## スコープ

**含まれるもの:**

- **Workspace管理（CRUD）**: Workspaceの作成・一覧表示・オープン・削除
- **Repository管理**: リモートリポジトリURLの登録、Bare Repositoryとしてのローカルキャッシュ、auto-fetch
- **Worktree操作**: Workspace作成時のWorktree自動生成、削除時のWorktree自動消去
- **エディタ連携**: `.code-workspace` ファイルの自動生成とVS Code起動
- **永続化**: Workspace設定（リポジトリ×ブランチの組み合わせ）のアプリ再起動後の保持
- **データ隔離**: 全データの `~/.squad` 配下への格納

**含まれないもの:**

- VS Code以外のエディタ対応（JetBrains等）
- Git操作のGUI化（commit, push, merge等）
- CI/CDパイプラインとの連携
- チーム間でのWorkspace設定共有・同期
- リポジトリ内のコンフリクト解決支援
- Docker / Dev Container との統合
