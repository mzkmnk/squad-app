# Intent: ブランチ選択オートコンプリート

## ビジネス目的

Workspace 作成時のブランチ選択を、現在のドロップダウン（`brn-select`）からテキスト入力 + オートコンプリートに変更する。
リモートブランチが多数あるリポジトリでは、ドロップダウンからの選択が非効率であり、部分一致フィルタリングによる素早い絞り込みが求められている。
また、既存ブランチに該当しない入力値で新規ブランチを作成できるようにすることで、Workspace 作成フローの中でブランチ作成まで完結させる。

## ステークホルダー

- **Primary**: 複数リポジトリを横断して開発する開発者（SquadApp ユーザー）
- **Secondary**: チームリーダー（Workspace 構成の標準化を推進する立場）

## 期待される成果

- ブランチ選択の操作時間短縮（特にブランチ数が多いリポジトリで顕著）
- Workspace 作成フロー内でのブランチ新規作成が可能になり、外部ターミナルでの操作が不要に
- 入力ミスの低減（部分一致による候補表示で正確なブランチ名を選択できる）

## スコープ

**含まれるもの:**

- Workspace 作成フォーム内のブランチ選択 UI をテキスト入力 + オートコンプリートに変更
- 入力値による部分一致フィルタリング（大文字小文字を区別しない）
- 候補リストからの選択
- 「新規作成」ボタンから新規ブランチ作成ダイアログを表示
- ダイアログ内で起点ブランチ（オートコンプリートで選択）と新規ブランチ名の入力
- 新規ブランチ名のバリデーション（既存の `validateBranchName` を活用）・重複チェック

**含まれないもの:**

- ブランチの削除・リネーム機能
- リポジトリ一覧画面でのブランチ管理 UI
- ブランチのお気に入り・最近使用した履歴
