# Unit of Work 分解計画 — IDE Selector & Settings

## 分解方針

SquadApp はモノリス（Electron デスクトップアプリ）のため、1 つの Unit of Work = アプリ全体とし、内部を Module で分割する。
ただし本機能は Electron 側（設定基盤 + IDE 検出 + IPC）と Angular 側（設定 UI）で明確に分離できるため、2 Unit に分割する。

## 分解結果

| Unit | 名前                                  | 責務                                                        |
| ---- | ------------------------------------- | ----------------------------------------------------------- |
| 1    | 設定基盤 & IDE 検出 & IPC（Electron） | 設定永続化、IDE 検出、IPC チャネル、preload、Workspace 変更 |
| 2    | 設定 UI（Angular）                    | 設定画面コンポーネント、サイドバーナビ、ルーティング        |

## 実行順序

Unit 1 → Unit 2（Unit 2 は Unit 1 の IPC API に依存）
