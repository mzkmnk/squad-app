# 要件検証質問 — IDE Selector & Settings

## 機能要件

### Q1: サポート対象の IDE

現在 VS Code がハードコードされています。サポートする IDE の範囲を教えてください。

- (a) VS Code + Cursor の2つのみ
- (b) VS Code + Cursor + その他（Windsurf, Zed 等）
- (c) ユーザーがカスタムコマンドを登録できる拡張可能な設計

[Answer]:

- vscode
- webstorm
- kiro ide

### Q2: IDE 選択の粒度

IDE の設定はどのレベルで行いますか？

- (a) アプリ全体で1つの IDE を設定（グローバル設定のみ）
- (b) グローバル設定 + Workspace ごとにオーバーライド可能
- (c) グローバル設定 + リポジトリごと + Workspace ごとの3階層

[Answer]: a

### Q3: IDE の自動検出

インストール済みの IDE を自動検出する機能は必要ですか？

- (a) 不要。ユーザーが手動で選択する
- (b) 必要。起動コマンドの存在チェック（`which code`, `which cursor` 等）で検出する
- (c) 必要。検出 + 未インストール IDE はグレーアウト表示する

[Answer]: c

### Q4: Workspace 作成時の IDE 選択

Workspace 作成ダイアログで IDE を選択できるようにしますか？

- (a) 不要。設定画面のグローバル設定に従う
- (b) 必要。作成時に IDE を選択でき、Workspace に紐づけて保存する
- (c) 必要。ただしデフォルトはグローバル設定で、変更したい場合のみ選択する

[Answer]: こちらですが、作成時はideを開かないようにしたい。

### Q5: 設定画面の配置

設定画面はどこに配置しますか？

- (a) サイドバーに「設定」ナビゲーション項目を追加し、専用ページとして表示
- (b) ヘッダーやサイドバーフッターに歯車アイコンを配置し、ダイアログで表示
- (c) その他（具体的に記述してください）

[Answer]: a

### Q6: 設定項目のスコープ

今回の設定画面には IDE 選択以外の設定項目も含めますか？

- (a) IDE 選択のみ。他の設定は将来追加
- (b) IDE 選択 + テーマ（ダーク/ライト）など基本設定も含める
- (c) 拡張可能な設定フレームワークとして設計し、IDE 選択を最初の項目とする

[Answer]: IDEのみ。ただこの後の要件で別の設定値も追加する予定。

## 非機能要件

### Q7: デフォルト IDE

初回起動時やマイグレーション時のデフォルト IDE は何にしますか？

- (a) VS Code（現在の動作を維持）
- (b) 初回起動時にユーザーに選択させる
- (c) 自動検出で最初に見つかった IDE をデフォルトにする

[Answer]:　デフォルトはvscode

### Q8: 既存データのマイグレーション

既存の `settings.json` が存在しない場合の初期化戦略は？

- (a) `SquadStore.initialize()` で `settings.json` も初期化する（既存パターンに合わせる）
- (b) 設定が必要になった時点で遅延初期化する

[Answer]: a

## エッジケース

### Q9: IDE が見つからない場合の動作

設定された IDE の起動コマンドが見つからない場合（アンインストール等）、どう動作すべきですか？

- (a) エラーメッセージを表示し、設定画面への誘導リンクを出す
- (b) フォールバックとして VS Code を試行し、それも失敗したらエラー
- (c) Workspace 作成/オープン自体は成功とし、IDE 起動失敗のみ通知する（現在の動作と同様）

[Answer]:
これは `Q4` でworkspace作成時に開かないようにしたため、workspace作成時のことは考慮しなくていい。
そのため、workspace一覧で開こうとして、 IDEが見つからない場合、エラーメッセージ等を出し、設定から変更を促すようにすればいい。
