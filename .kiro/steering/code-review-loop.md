# コードレビューループ

タスクの実装が完了したら、以下のプロセスに従ってコードレビューを実施すること。

## プロセス

1. 実装タスクが完了したら、`code-reviewer` サブエージェントを起動し、変更したファイルのレビューを依頼する
2. レビュー結果に「必須修正（Must Fix）」または「推奨修正（Should Fix）」がある場合、指摘事項を修正する
3. 修正後、再度 `code-reviewer` サブエージェントにレビューを依頼する
4. LGTM（指摘事項なし、または「提案」のみ）になるまで 2〜3 を繰り返す
5. LGTM を得たら、レビュー完了をユーザに報告する

## サブエージェント呼び出し例

```
invokeSubAgent(
  name: "code-reviewer",
  prompt: "以下の変更ファイルをレビューしてください:\n- <変更ファイル一覧>\n\n変更内容の概要: <変更概要>",
  explanation: "実装完了後のコードレビュー"
)
```

## 注意事項

- 「🟢 提案（Nice to Have）」のみの場合は LGTM とみなし、提案内容をユーザに共有するだけでよい
- レビュー対象は今回のタスクで変更・作成したファイルのみとする
