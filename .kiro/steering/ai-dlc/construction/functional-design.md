# AI-DLC Construction: Functional Design（条件付き、Unit 単位）

Inception の Application Design で定義したコンポーネントの詳細ビジネスロジックを設計する。

## 実行条件

- 新しいデータモデルやスキーマが必要
- 複雑なビジネスロジックがある
- ビジネスルールの詳細設計が必要

## スキップ条件

- 単純なロジック変更
- 新しいビジネスロジックがない

## 手順（Planning → Generation の2パート）

### Part 1 - Planning

1. 設計計画を作成（チェックボックス付き）
2. コンテキストに応じた質問を `[Answer]:` タグで生成
3. ユーザー回答を収集・曖昧さ分析
4. 計画の承認を得る

### Part 2 - Generation

1. 承認された計画に基づき設計成果物を生成
2. チェックボックスを即座に更新

## 本プロジェクトでの成果物

SquadApp は Electron デスクトップアプリのため、公式テンプレートを以下に適応:

- **データモデル** → zod スキーマ定義、TypeScript 型定義
- **API 仕様** → IPC チャネル仕様（チャネル名、リクエスト型、レスポンス型）
- **ビジネスルール** → バリデーションルール、エラーハンドリング仕様
- **コンポーネント構成** → Angular コンポーネント/サービス + Electron サービスの配置

## 成果物

- `docs/aidlc/{feature_name}/construction/{unit_name}/design.md`

## 成果物テンプレート

```markdown

## データモデル（zod スキーマ）

## IPC チャネル仕様

```
