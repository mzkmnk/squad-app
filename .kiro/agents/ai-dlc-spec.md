# AI-DLC Inception: Intent & Story

これより、AI-DLCの要件定義フェーズを開始します。
まず、今回の機能開発の識別子となる「機能フォルダ名（feature_name）」を決定（例: `ticket-cancellation`）し、以下の構造を作成してください。

`docs/aidlc/[feature_name]/inception/`

その後、以下の手順を実行してください。

1. **Intent Definition**:
   - 要望から「ビジネス目的」を定義し、`intent.md` を上記フォルダに作成する。

2. **User Story**:
   - 承認されたIntentに基づき「ユーザーストーリー」と「受入条件」を定義し、`story.md` を上記フォルダに作成する。

**アクション:**
まず「今回の機能のフォルダ名を何にするか」を私に提案・確認してください。

---

## テンプレート: intent.md

```markdown
# Intent: [機能名]

## ビジネス目的

[この機能を開発する理由、解決したい課題]

## ステークホルダー

- **Primary**: [主要な利用者・関係者]
- **Secondary**: [副次的な利用者・関係者]

## 期待される成果

- [期待される具体的な成果1]
- [期待される具体的な成果2]

## スコープ

**含まれるもの:**

- [スコープ内の項目1]
- [スコープ内の項目2]

**含まれないもの:**

- [スコープ外の項目1]
- [スコープ外の項目2]

## 更新履歴

| 日付       | 内容     |
| ---------- | -------- |
| YYYY-MM-DD | 初版作成 |
```

## テンプレート: story.md

```markdown
# User Story: [機能名]

## ユーザーストーリー（EARS形式）

**WHEN** [トリガーとなる状況]
**IF** [条件（オプション）]
**THEN** [システムが行うべきこと]

### 例

**WHEN** ユーザーがチケットキャンセルボタンをクリックした時
**IF** キャンセル可能期限内である
**THEN** システムはキャンセル確認ダイアログを表示する

## 受入条件（Given-When-Then形式）

### AC1: [受入条件のタイトル]

- **Given** [前提条件]
- **When** [実行するアクション]
- **Then** [期待される結果]

### AC2: [受入条件のタイトル]

- **Given** [前提条件]
- **When** [実行するアクション]
- **Then** [期待される結果]

## 非機能要件

### パフォーマンス

- [要件1]

### セキュリティ

- [要件1]

### アクセシビリティ

- [要件1]

## 更新履歴

| 日付       | 内容     |
| ---------- | -------- |
| YYYY-MM-DD | 初版作成 |
```
